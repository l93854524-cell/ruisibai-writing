# 八讲题型流程

先读完整题目。以下是课程模板的可执行摘要；固定句数仅作课堂示范，题目要求优先。出处详见 [source-provenance.md](source-provenance.md)。

| 课次 | 题型 | 写作顺序与核对重点 |
|---|---|---|
| P1 | 问题解决 | 提出问题与过渡 → 可用三组“办法／论点＋对应论据” → 重申观点与期望。学生至少要能自写与题目有关的简单句。 |
| P2 | 观点选择 | 交代选项 → 明确选择 → 用理由支持 → 收束。第一段常比 P1 多出列选项与立场的内容；理由可写所选方案的优点，或未选方案的缺点。 |
| P3 | 现象解释 | 描述现象与观点 → 分析原因、影响或题目指定角度 → 总结。每组解释需与所说现象对应。 |
| P4 | 谚语 | 引用谚语 → 用自己的话解释 → 过渡到论证；后两段可借用议论文框架。示例要真正说明谚语含义。 |
| P5 | 图画 | 描述画面及配文 → 点明含义或问题 → 按题目展开论证。只写可见信息；时态按所表达的情境选择。 |
| P6 | 新闻报道 | 客观交代事件及结果 → 写时间、地点、人物、过程等细节 → 说明意义。报道已发生事件时注意第三人称与过去时。 |
| P7 | 信件 | 核对题目要求的日期、称呼、正文、结束语与署名 → 表明身份和目的 → 逐项覆盖信息点。日期只在题目给出或需要时写；简化句子后仍核对信息完整性。 |
| P8 | 通知 | 核对标题、日期、发布者 → 写目的、时间、地点、对象及题目指定事项 → 为要点补一句相关说明，末尾按需给联系方式。将来活动可用将来时。 |

## 按任务使用

- **审题**：给出题型判断、必写信息清单和一条理由；无法判断时说明待确认之处。
- **构思**：给可填写的分段骨架；议论文的每个论点后放相应论据；应用文逐项对应题目要求。
- **逐句练习**：先让学生写一条与题目有关的简单句，再考虑逻辑词与固定表达。
- **范文**：完整覆盖题目要求，语言自然；不为套模板添无关内容。

P4、P5 借用议论文后续结构属于 **[课程明确]**；“完整题目优先”、可调整论点数量、英文自然度检查属于 **[v1.2 补充]**。课程里的考题年份与考试概率判断仅记录历史讲课语境，不用于预测当前考试。
